# Day 5: Batch Processor

A small Python project for processing multiple inputs in one run and saving the outputs for review.

## Why I built it

I wanted hands-on experience of moving beyond one-off AI requests and working with larger sets of inputs in a more structured and repeatable way.

## What it does

- Processes multiple inputs in batches
- Applies the same task consistently across each item
- Saves outputs for later review
- Supports a more efficient workflow than handling each item individually

## What I learned

This project helped me understand how repeatable AI workflows can be organised, how consistency matters across larger sets of inputs, and how outputs need to be structured so they can be reviewed properly.

## Why it matters to my work

My work often involves evaluating patterns across multiple pieces of content rather than looking at one item in isolation. This project gave me practical experience of building a simple repeatable workflow that supports consistency, review and quality control.
